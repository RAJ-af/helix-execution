# Helix AI - Installation Guide

## Minimum Requirements
- **Android**: API Level 26 (Android 8.0) or higher.
- **Device Architecture**: ARM64-v8a optimized.

## Installation Steps
1. Download `helix-debug.apk` or `helix-release.apk`.
2. Transfer to your device.
3. Enable "Install from Unknown Sources" in Android Settings.
4. Open the APK and follow the prompts.

## Required Permissions
- **Internet**: Required for AI communication and Search.

## Backend Setup
The app requires the Helix Backend to be running.
Default address for Emulator: `http://10.0.2.2:8000`
For real devices: Update `Config.BASE_URL` to your local IP.
